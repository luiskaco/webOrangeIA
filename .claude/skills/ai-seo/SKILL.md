# AI SEO (AEO/GEO)

Skill nativa de Claude Code, no publicada en el registro de `npx skills add`
— no requiere instalación aparte, ya está disponible al usar Claude Code.

## Cuándo activarla

Al optimizar contenido para que aparezca citado en respuestas de IA
(AI Overviews de Google, ChatGPT, Perplexity, Claude, Gemini) en vez de (o
además de) rankear en resultados de búsqueda tradicionales. Relevante para
portales de contenido/reportes donde la visibilidad en IA empieza a pesar
tanto como el SEO clásico.

Trabaja junto a [`seo-audit`](../seo-audit/SKILL.md): `seo-audit` diagnostica
SEO técnico tradicional (meta tags, Core Web Vitals, indexación);
`ai-seo` se enfoca en citabilidad/extraibilidad del contenido por sistemas
de IA — son capas distintas, no compiten.

## Instalación

No aplica — es una skill del propio Claude Code, disponible sin paso extra.
Si se usa fuera de Claude Code (ej. con Antigravity/Gemini), copiar el
contenido de esta carpeta a mano.
